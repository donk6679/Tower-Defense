Audio folder layout
===================

Short sound effects:  Assets/Resources/Audio/SFX/<name>.wav
Background music:     Assets/Resources/Audio/BGM/<name>.ogg (or .wav / .mp3)

Expected SFX names (missing files are simply skipped):
  click             UI button click
  build             tower built
  upgrade           tower upgraded
  demolish          tower demolished
  shoot_gun         gun tower fires
  shoot_frost       frost tower fires
  shoot_sniper      sniper tower fires
  hit               projectile hits an enemy
  enemy_death       enemy killed
  life_lost         enemy reached the core
  wave_start        new wave starts spawning
  early_wave        player starts the next wave early
  victory           game won
  defeat            game lost

Expected BGM names:
  bgm_menu          main menu music
  bgm_battle        in-game music
